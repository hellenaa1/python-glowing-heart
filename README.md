# ❤️ Python Glowing Heart Animation

A creative coding project that uses Python to generate a glowing heart effect using mathematical equations, random particles, and Turtle graphics.

## ✨ Features

- Heart shape generated using mathematical equations.
- Randomized particles and line strokes.
- Pink and purple colors against a black background.
- Adjustable particle density, colors, and stroke lengths.
- An exploration of mathematical art using Python.

## 🛠️ Technologies Used

- Python
- Turtle
- Math
- Random

## 🚀 How to Run

### Requirements

- Python 3 installed on your computer.
- No additional packages are required for the standard Turtle version.

### Installation

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python glowing_heart.py
```

If your Python installation uses the `py` command, run:

```bash
py glowing_heart.py
```

A window will open displaying the heart animation.

## 🎨 Customization

Experiment with the code to change:

- The number of particles.
- The heart's size.
- The colors and brightness.
- The length and direction of the strokes.
- The animation speed, if using the animated version.
